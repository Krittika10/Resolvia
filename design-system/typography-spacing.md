
# Resolvia — Typography and Spacing System

Version: 1.0

## 1. Font Families

Primary:
Inter

Usage:
- Page headings
- Navigation
- Body content
- Forms
- Buttons

Technical:
IBM Plex Mono

Usage:
- Issue identifiers
- Timestamps
- Technical metadata
- Log references

Fallbacks:
- Inter, Arial, sans-serif
- IBM Plex Mono, monospace

## 2. Typography Scale

| Element | Size | Weight |
|---|---:|---|
| Page heading | 26px | 600 |
| Section heading | 17px | 600 |
| Subheading | 15px | 600 |
| Body | 14px | 400 |
| Navigation | 13px | 500 |
| Metadata | 12px | 400 |
| Technical label | 11px | 500 |

## 3. Spacing Scale

Base unit: 4px

| Token | Value |
|---|---:|
| XS | 4px |
| SM | 8px |
| MD | 12px |
| LG | 16px |
| XL | 24px |
| 2XL | 32px |
| 3XL | 48px |

## 5. Corner Radius

| Component | Radius |
|---|---:|
| Small controls | 4px |
| Panels | 6px |
| Modals | 8px |

## 6. Design Rules

1. Use a consistent 4px spacing grid.
2. Keep typography hierarchy consistent.
3. Use monospace only for technical information.
4. Avoid excessive font weights.
5. Maintain readable line lengths.
6. Keep interface density compact but comfortable.
7. Avoid unnecessary shadows and rounded containers.
